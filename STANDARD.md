# Стандарт

## Разделение ответственности

- `src/strategy/` — только математика: свечи → фичи → сигнал. Не знает про
  биржу, БД, Telegram.
- `src/risk/` — только чистые числа (баланс, PnL, размер лота). Не знает
  про SQLite, биржу, откуда пришли данные.
- `src/exchange/` — только исполнение ордеров и получение баланса/свечей
  через `BaseExchange`. Не знает про стратегию и риск.
- `src/services/` — обвязка на событиях, обращается к бирже только через
  `BaseExchange`, к ccxt напрямую не обращается.
- `src/bot/` — Telegram-интерфейс, к БД и бирже — только через готовые
  функции/методы, не напрямую SQL.

Эти правила уже выполняются текущим кодом — воспроизводить их отдельным
диаграммным документом не нужно, достаточно не нарушать при правках.

## Единственное жёсткое правило по модели

Файл модели (`models/saved_models/*.pkl`) может быть перезаписан только
скриптом `scripts/train.py`, и только если пройден gate (см. `ROADMAP.md`,
шаг 1). Ручная подмена `.pkl` в обход gate — запрещена, даже "на минуту
проверить".

## Технологический стек

Python 3.12+, asyncio, aiogram 3, SQLite (WAL), LightGBM, pandas/numpy
(`float32` для фич). Без Redis, без очередей, без ORM поверх нескольких
БД — под ограничение 2 ГБ RAM ВПС.

## Тесты

`python -m pytest tests/` обязателен перед любым деплоем — это уже
настроено в CI (`.github/workflows/deploy.yml`), сборка образа не
запускается, если тесты красные.
