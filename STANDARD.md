# 🏛 Стандарт Архитектуры MarketMind v1.0

### 1. Архитектурное разделение
Система строится на двух независимых контурах
 Trading Core (247) Легковесный асинхронный процесс Python 3.12 (~100 МБ RAM). Отвечает за прием свечей, проверку рисков и исполнение ордеров.
 Research Lab (On-Demand) Модульный конвейер исследований. Запускается по требованию, строит эксперименты, проверяет OOS-метрики и выгружает артефакты в `artifactsexperimentsexp_XXXX`.

---

### 2. Законы Исследовательского Конвейера (Research Rules)

1. Закон общего кода фичей
   Запрещено создавать дублирующие скрипты фичей в `research`. Исследовательский конвейер обязан импортировать расчет индикаторов из `srcstrategyfeatures.py`.

2. Закон атомарности эксперимента
   Запрещено переписывать файлы моделей «напрямую». Каждая итерация исследований генерирует новую папку `exp_XXXX` с сохранением конфига, хэша датасета, прогнозов и отчета.

3. Закон Purged Walk-Forward
   Валидация обязана использовать разрыв (Purge Gap) между Train и Test фолдами, равный горизонту удержания позиции (`DEFAULT_TIMEOUT_CANDLES`).

4. Закон учета издержек (Friction-First)
   Бэктест обязателен к прогону с учетом комиссий (по умолчанию $0.08%$ за круг) и проскальзывания ($ge 0.04%$). Модели с чистым ожиданием $ 0.1%$ за сделку отбраковываются.

5. Закон изоляции деплоя
   Research не обновляет боевую модель `modelsactive.pkl`. Обновление выполняет только `scriptspromote_candidate.py` после прохождения Quality Gate.

---

### 3. Технологический стек
 ЯзыкФреймворк Python 3.12+, Asyncio, Aiogram 3.
 База Данных SQLite WAL mode (`PRAGMA journal_mode=WAL; busy_timeout=5000;`).
 Формат Артефактов Parquet (данныепрогнозы), YAML (конфиги), JSON (метрики), PKL (модели).
 ML LightGBM (`float32`), Scikit-learn, Pandas, NumPy.
