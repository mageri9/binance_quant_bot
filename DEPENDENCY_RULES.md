# ⛔ Документ 2: Правила Зависимостей (Dependency Rules)

Чтобы архитектура не деградировала, устанавливаются **жесткие запреты на импорты и вызовы**:

```text
┌──────────────────┐       ┌──────────────────┐       ┌──────────────────┐
│   Strategy Core  │ ──►── │    Risk Core     │ ──►── │  Execution Core  │
└──────────────────┘       └──────────────────┘       └──────────────────┘
         │                          │                          │
         ❌                         ❌                         ❌
   НЕ ИМПОРТИРУЕТ             НЕ ИМПОРТИРУЕТ             НЕ ИМПОРТИРУЕТ
 Execution / Exchange        SQLite / DB Models        Market / FeatureBuilder
```

### Таблица Запрещенных Связей:

| Модуль | Запрещено импортировать / знать о... | Почему |
| :--- | :--- | :--- |
| **`src/strategy/`** | `ExecutionService`, `Exchange`, `ccxt`, `SQLAlchemy`, `Trade` | Стратегия — чистая математика (свечи → индикаторы → сигнал). |
| **`src/risk/`** | `SQLite`, `MarketService`, `ccxt`, `Aiogram` | Риск-модуль не знает, откуда пришли данные, он валидирует чистые цифры (баланс, PnL, размер лота). |
| **`src/exchange/`** | `Strategy`, `Risk`, `Aiogram`, `PredictionLog` | Биржевой адаптер умеет только исполнять ордера и отдавать баланс/свечи. |
| **`src/services/`** | `ccxt` напрямую | Все биржевые операции только через интерфейс `BaseExchange`. |
| **`src/bot/`** | `ccxt`, прямые SQL-запросы | Бот общается с биржей только через методы `BaseExchange`, с историей — через CRUD/БД. |
